# インデックス登録チェックリスト

Google スプレッドシートで、Search Console のインデックス登録状況を管理するためのリストです。

## このリストに含まれるページ

| 種類 | 件数 | 例 |
|------|------|-----|
| トップ・ランキング | 2 | `/` `/rankings` |
| 作品詳細ページ | 87 | `/works/mushoku-tensei-3` など（`share_slug` の ASCII URL） |

**合計 89 ページ**（`data/works.json` の 87 作品 + トップ・ランキング）

**進捗（2026/7/3 更新）**: インデックス登録リクエスト **済 13件** ／ 未着手 **76件**

> シーズン切り替えはトップのプルダウン、または `/?season=2026-spring` / `/?season=2026-summer` で行えます。デフォルトは2026年夏アニメです。

## 列の意味

| 列名 | 使い方 |
|------|--------|
| **優先度** | ★★★＝人気上位5作品、★★☆＝次点5作品＋ハブ2ページ、★☆☆＝その他 |
| **ページ名** | ページのタイトル（管理用） |
| **URL（フル）** | Search Console に貼り付ける完全 URL |
| **インデックス登録リクエスト** | GSC で「インデックス登録をリクエスト」したら「済」や日付を記入 |
| **site:検索で確認** | Google で `site:anime-gensaku-guide.onrender.com キーワード` を検索し、表示されたら「済」 |
| **メモ** | 自由記入 |

## Google スプレッドシートと CSV の関係（重要）

毎朝のリマインダーメール（`tools/gsc_reminder.py`）は **Google スプレッドシートではなく、リポジトリ内の `docs/インデックス登録チェックリスト.csv` を直接読みます**。スプレッドシートだけを更新しても、メールの「今日の2件」は変わりません。

| やりたいこと | 手順 |
|--------------|------|
| スプレッドシートで管理しつつメールも合わせたい | CSV を正として編集 → スプレッドシートにコピー／再インポート |
| スプレッドシートで済を付けた | 同じ内容を CSV の「インデックス登録リクエスト」列に写す（または CSV をエクスポートしてシートに貼り付け） |
| リモートからスプレッドシートだけ更新 | **不可**（Google Sheets API の設定がない限り、こちらからシートは編集できません） |

**おすすめ**: 進捗を付けたら **必ず CSV も更新**する。スプレッドシートは閲覧・メモ用のミラーとして使うイメージです。

## Google スプレッドシートへの取り込み方

### 方法A：新しいスプレッドシートに取り込む（おすすめ）

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. 左上 **「空白」** で新しいシートを作成
3. メニュー **「ファイル」→「インポート」**
4. **「アップロード」** タブで `インデックス登録チェックリスト.csv` を選ぶ
5. インポート設定：
   - **場所**：「新しいシートを挿入する」
   - **区切り文字の種類**：「カンマ」
   - **文字コード**：「UTF-8」（文字化けする場合は「Unicode (UTF-8)」を試す）
6. **「データをインポート」** をクリック

### 方法B：既存のシートに追記する

1. スプレッドシートを開く
2. **「ファイル」→「インポート」**
3. CSV をアップロード
4. **場所**：「現在のシートを置換する」または「現在のシートの下に挿入する」

## 使い方の流れ（1ページあたり）

1. **URL（フル）** をコピー
2. [Google Search Console](https://search.google.com/search-console) → **URL 検査** に貼り付け
3. 「インデックス登録をリクエスト」を実行したら、**インデックス登録リクエスト** 列に「済」や日付を書く
4. 数日後、Google 検索で `site:anime-gensaku-guide.onrender.com` とページ名で検索
5. 検索結果に出たら **site:検索で確認** 列に「済」と日付を書く

## 優先度の目安

- **★★★ から順に** 登録リクエストすると効率的です（`watchers_count` 上位5作品）
- トップ・ランキングは 6/28 時点で site: 検索確認済み（CSV に反映済み）
- 作品 URL は必ず `share_slug`（ASCII）を使用: `/works/{share_slug}`

## 作品を追加したとき

`data/works.json` に作品を追加したあと、次のコマンドで CSV を再生成できます。

```
python tools/generate_index_checklist.py
```

生成後、スプレッドシートを再度インポートするか、追加分だけ手でコピーしてください。
