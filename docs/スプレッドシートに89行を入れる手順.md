# スプレッドシートに89行を入れる手順

`スプレッドシート連携テスト.bat` は **スプレッドシートから読み取るだけ** です。  
行を増やしたいときは、**PCのCSVをスプレッドシートに入れる**必要があります。

---

## 手順（3ステップ）

### 1. PCでCSVを用意する

プロジェクトフォルダの **`チェックリストをCSVで書き出し.bat`** をダブルクリック。

または、すでに次のファイルがあればそのまま使えます：

`docs/インデックス登録チェックリスト.csv`（**89行**あること）

### 2. Googleスプレッドシートにインポートする

1. [Google スプレッドシート](https://sheets.google.com) を開く（いつものチェックリスト）
2. メニュー **ファイル** → **インポート**
3. **アップロード** タブ → 手順1の CSV を選ぶ
4. **インポート場所** で **データを置き換える** を選ぶ
5. **データをインポート** をクリック

約 **89行**（見出し1行＋データ89行）になればOKです。

### 3. 連携テストをもう一度実行

プロジェクトフォルダの **`スプレッドシート連携テスト.bat`** をダブルクリック。

成功例：

```
スプレッドシートから取得: 89行 → ...\docs\インデックス登録チェックリスト.csv
OK: 89行を読み込みました
```

---

## よくある勘違い

| 思い込み | 実際 |
|----------|------|
| テストbatを実行するとシートに行が増える | **増えません**（読み取りのみ） |
| ローカルCSVを編集すればシートも変わる | **変わりません**（シートが正） |
| シートが23行だとローカルも23行になる | **以前は上書きされていました** → 今は89行より少ない取得ではローカルを守ります |

---

## 日常の使い方

- **済** や日付は **Googleスプレッドシート** の「インデックス登録リクエスト」列に書く
- 毎朝のメールはスプレッドシートの最新を自動取得
- 作品が増えたときだけ、もう一度「CSV書き出し → インポート（置き換え）」
