# X（Twitter）運用チェックリスト

アニメ原作ガイド（https://anime-gensaku-guide.onrender.com）をXで毎日1本ずつ紹介するための手順書です。  
**1日15分**を目安に、下の順番どおり進めてください。

---

## Phase 1: サイト側（Cursorが実装済み）

以下はすでにサイトに入っています。特別な操作は不要です。

| 機能 | 内容 |
|------|------|
| OGカード | 作品ページに `og:image`（表紙）・タイトル・説明が入る。XでURLを貼るとプレビューに表紙が出る |
| Xシェア文 | 各作品に約100文字の投稿文を自動生成（ハッシュタグ2個付き） |
| シェアボタン | 作品詳細ページに「Xでシェア」「文面をコピー」ボタン |
| シェアURL | 日本語IDではなく `share_slug`（例: `/works/mushoku-tensei-3`）を使用 |

**OGカードの確認方法（任意）**

- [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) に作品URLを貼って「もう一度スクレイピング」
- または [Twitter Card Validator](https://cards-dev.twitter.com/validator)（要ログイン）

**テスト用URL例**

- 無職転生: https://anime-gensaku-guide.onrender.com/works/mushoku-tensei-3
- Re:ゼロ: https://anime-gensaku-guide.onrender.com/works/re-zero-4th-dakkan
- ワンパンマン: https://anime-gensaku-guide.onrender.com/works/onepunch-man-3

## Phase 2: 初回セットアップ（1回だけ）

### 2-1. プロフィールを整える

1. Xのプロフィール編集を開く
2. **ウェブサイト** に `https://anime-gensaku-guide.onrender.com` を設定
3. 自己紹介に「今期アニメの原作ガイド」など一言入れる

### 2-2. 固定ポストを作成する

1. 新規投稿を作成
2. 下の「固定ポスト用の文例」をコピーして貼り付け
3. 投稿後、⋯メニュー → **ポストをプロフィールに固定**

**固定ポスト用の文例**

```
📚 今期アニメの「原作は何巻から？」をまとめたサイトです

✅ アニメ化範囲・続きの巻数
✅ 読む順・Amazonリンク付き

毎日1作品ずつ紹介していきます👇
https://anime-gensaku-guide.onrender.com

#アニメ #原作
```

## Phase 3: 毎日のルーティン（15分）

| 順番 | やること | 詳細 |
|------|----------|------|
| 1 | 作品を1つ選ぶ | `docs/インデックス登録チェックリスト.csv` から未投稿のものを選ぶ |
| 2 | 詳細ページを開く | サイトの一覧 → 作品名をクリック |
| 3 | 表紙画像を保存 | 表紙を**右クリック →「画像を保存」** |
| 4 | Xで投稿を作成 | 画像を添付 →「Xでシェア」または「文面をコピー」で文面を入れる |
| 5 | 19〜22時に投稿 | この時間帯が反応が取りやすい目安 |
| 6 | ハッシュタグ確認 | 文面の末尾に2〜3個入っているか確認（足りなければ追加） |

### 投稿の流れ（画像付き）

1. Xの投稿画面を開く
2. **画像を添付**（手順3で保存した表紙）
3. 作品ページの **「文面をコピー」** を押す → Xの本文に貼り付け
4. **「Xでシェア」** を押すと、文面＋URLが自動で入る（画像は別途添付が必要）
5. プレビューで表紙・タイトルが表示されるか確認
6. **19〜22時** に投稿

### 投稿文の例（サイトが自動生成するイメージ）

**無職転生Ⅲ**

```
【無職転生Ⅲ】原作は第13巻から。アニメ追ってる人向け👇 #異世界 #ファンタジー
https://anime-gensaku-guide.onrender.com/works/mushoku-tensei-3
```

**Re:ゼロ 4th season 奪還編**

```
【Re:ゼロから始める異世界生活 4th season 奪還編】原作は第21巻から。アニメ追ってる人向け👇 #異世界 #ダーク
https://anime-gensaku-guide.onrender.com/works/re-zero-4th-dakkan
```

**ワンパンマン 第3期**

```
【ワンパンマン 第3期】原作は第17巻から。アニメ追ってる人向け👇 #バトル #ギャグ
https://anime-gensaku-guide.onrender.com/works/onepunch-man-3
```

## Phase 4: 週1のお手入れ

### 引用RT（週1回）

1. 過去に反応が良かった自分の投稿を開く
2. **引用** を押す
3. 一言コメントを足す（例:「まだ読んでない人はこの巻から👇」）
4. 投稿

### 固定ポストの更新（月1回程度）

- 新シーズンが始まったら固定ポストの文面を更新
- 人気作品へのリンクを差し替えてもOK

## やらなくていいこと（サイト側で対応済み）

- URLの手打ち（シェアボタンで自動）
- 投稿文の一から作成（自動生成＋コピーボタン）
- OG画像の手動設定（表紙が自動でプレビューに出る）

## 自分でやること（コードでは自動化できない）

- 画像の手動添付（Xの仕様上、サイトから直接は送れない）
- 投稿時間の調整（19〜22時推奨）
- 固定ポスト・引用RT
- 毎日1本のペース管理

---

## 困ったとき

| 症状 | 対処 |
|------|------|
| リンクに表紙が出ない | Facebook Debugger でURLを再スクレイピング。数分待って再確認 |
| 文面が長い | 作品ページのプレビューを確認。ハッシュタグを1個減らしてもOK |
| どの作品を投稿するか迷う | `インデックス登録チェックリスト.csv` の★★★から順に |
