# インデックス登録チェックリスト — Googleスプレッドシート連携

## 1本化のルール（これが正解）

| 役割 | どこ | あなたがやること |
|------|------|------------------|
| **正（マスター）** | Googleスプレッドシート | 毎日「済」を書くのはここだけ |
| 自動ミラー | `docs/インデックス登録チェックリスト.csv` | リマインダーがシートから取得して上書き |
| 作品追加時だけ | 貼付用CSVを再インポート | チャットにCSVを送る必要なし（作品が増えたときだけ再生成） |

普段の進捗をチャットに送って別ファイル管理する必要はありません。  
**シートを更新すればOK**です（`.env` の `CHECKLIST_SHEET_URL` が、今使っているシートを指していること）。

作品をサイトに追加したあと行数が足りなくなったときだけ:

```bash
python tools/generate_index_checklist.py --also-sheet-import
```

できた `docs/インデックス登録チェックリスト_スプレッドシート貼付用.csv` をシートに「現在のシートを置き換える」で入れ直す。  
（ローカルCSVの「済」は自動で引き継ぎます。シート側の最新「済」を残したいときは、先にシートをCSVダウンロードして `--merge-csv そのファイル` を付けて再生成）

## 最初に1回だけやること

### 1. スプレッドシートを作る

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. **空白**のスプレッドシートを新規作成
3. 左下のシート名（タブ）を **`インデックス登録チェックリスト`** に変更（任意ですが分かりやすく）

### 2. 今のデータを貼り付ける（初回／全件更新時）

次のどちらかを使います（中身は同じ）:

- `docs/インデックス登録チェックリスト_スプレッドシート貼付用.csv`
- または `Downloads/インデックス登録チェックリスト_最新_貼付用.csv`

**手順（Googleスプレッドシート上）：**

1. メニュー **ファイル** → **インポート**
2. **アップロード** タブ → 上の CSV ファイルを選ぶ
3. インポート場所：**現在のシートを置き換える**
4. 区切り文字：**カンマ**
5. **データをインポート** をクリック

**約140行**（作品134 + トップ・ランキング・まとめ4）になればOKです。

### 3. 列の形式（この順番・名前を守る）

1行目（見出し行）は次のとおりにしてください：

| 列 | 見出し名 |
|----|----------|
| A | 優先度 |
| B | ページ名 |
| C | URL（フル） |
| D | インデックス登録リクエスト |
| E | site:検索で確認 |
| F | メモ |

※ C列は `URL` でも動きますが、既存データに合わせて **`URL（フル）`** を推奨します。

「インデックス登録リクエスト」列に **済** や日付を入れると、その行はメールの候補から外れます。

## 共有設定（リンクを知っている全員が閲覧可）

スクリプトがデータを読むには、**閲覧できる状態**にする必要があります。

1. スプレッドシート右上の **共有** をクリック
2. **一般的なアクセス** を **リンクを知っている全員** に変更
3. 権限を **閲覧者** にする（編集はあなただけでOK）
4. **完了**

## スプレッドシートID と gid の調べ方

### スプレッドシートID

ブラウザのアドレスバーの URL から取ります。

```
https://docs.google.com/spreadsheets/d/【ここがスプレッドシートID】/edit?gid=0#gid=0
```

例：`1aBcDeFgHiJkLmNoPqRsTuVwXyZ1234567890abcdef`

### gid（シートタブの番号）

同じ URL の `gid=` の後ろの数字です。

```
...?gid=【ここがgid】#gid=【同じ数字】
```

- 最初のタブは多くの場合 `0`
- タブをクリックすると URL の `gid=` が変わります

---

## エクスポート用URLを作る

次の形に当てはめます（`{ID}` と `{GID}` を置き換え）：

```
https://docs.google.com/spreadsheets/d/{ID}/export?format=csv&gid={GID}
```

**例：**

```
https://docs.google.com/spreadsheets/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ1234567890abcdef/export?format=csv&gid=0
```

ブラウザでこの URL を開いて、表の内容が CSV のように見えれば成功です。

---

## .env に設定する

プロジェクトフォルダの `.env` をメモ帳で開き、次の1行を追加します：

```
CHECKLIST_SHEET_URL=https://docs.google.com/spreadsheets/d/（あなたのID）/export?format=csv&gid=（あなたのgid）
```

- `=` の後ろに、上で作った URL を**そのまま**貼り付け
- 行末に余計なスペースを入れない
- `.env` は Git に上げない（秘密情報と同じ扱い）

## 日常の使い方

1. **Googleスプレッドシートだけ編集**する（「済」マーク、メモなど）
2. 毎朝9時のリマインダーが、最新データを自動取得してメールに反映
3. 取得に成功すると、PC上の `docs/インデックス登録チェックリスト.csv` も**自動で上書きバックアップ**されます

ローカル CSV を直接編集しても、次回取得時にスプレッドシートの内容で上書きされます。**編集はスプレッドシート側で行ってください。**

## うまくいかないとき

| 症状 | 対処 |
|------|------|
| HTML と表示される | 共有が「閲覧可」になっているか確認 |
| シートの行がローカルより少ない | ローカルCSVは上書きしません。`docs/スプレッドシートに89行を入れる手順.md` でCSVを再インポート |
| 列がずれる | 1行目の見出し名が上表と一致しているか確認 |
| GitHub Actions から送る場合 | リポジトリの Secrets に `CHECKLIST_SHEET_URL` も登録 |
